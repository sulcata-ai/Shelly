# Shelly

A personal AI assistant: Claude, over Telegram, with modular capabilities.
Runs on the Jetson; the dashboard is `../Shelly-Web-App`. Design and roadmap are in `CLAUDE.md`.

```bash
/usr/local/bin/python3.13 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python -m shelly
```
